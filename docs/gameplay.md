# ゲーム仕様

数値そのものは `game/game.go`（速度・間隔・ナイトモード）と `game/enemy.go`（障害物の種類と解禁スコア）の定数を参照してください。ここには、定数を読んだだけでは分からない設計意図を書きます。

## 操作

- **ジャンプ**: Space / ↑ / クリック / タップ
- **長押しで高く跳ぶ**。離すと上昇が打ち切られるので、小サボテンはチョン押し、大サボテンや3連は長押し
- サボテンを飛び越え、低い鳥は飛び越え、高い鳥はくぐる（ジャンプすると当たる）

跳躍と当たり判定は `game/player.go`。

## 難易度の上げ方

速度は等加速度で上がり続けます（`speedAt`）。障害物は種類ごとに解禁スコアがあり、進むほど手札が増えます（`unlockedKinds`）。

間隔は固定フレーム数ではなく「その障害物自身の幅 × 速度 + 定数」を基準にしています（`minSpawnGap` / `maxSpawnGap`）。この式のおかげで、

- 幅の広い敵の後ほど距離が空く（避けきる時間が確保される）
- 速度が上がるほどフレーム換算では詰まる（体感の難度が上がる）

が同時に成り立ちます。`minSpawnPitch` が到達間隔の下限を押さえていて、速度が最高でも反応不能にはなりません。

最高速に到達したあとも難易度を上げ続けるため、`difficulty` がスコアに応じて 0→1 に向かい、間隔のばらつきが狭まって難しい敵の比率が上がります（`lerp` / `pickKind`）。同じ種類が3連続で出ないようにする抑制も `pickKind` にあります。

鳥は半分が地面より速く、半分が遅く飛びます（`bird.drift`）。地面と同じ速度で流れる障害物ばかりだと単調になるためです。

## ナイトモード

一定スコアごとに色が反転し、一定時間で戻ります（`game/game.go` の `nightTimer` 周り）。難易度には影響しません。
