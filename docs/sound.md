# 効果音

音声ファイルは持たず、起動時にサイン波から生成しています。ファームウェアのフラッシュ容量に収めるためと、アセットのライセンスを持ち込まないためです。

- 波形の生成: `internal/beep`（標準ライブラリのみ。ディスプレイ無しでテストできる）
- 音色と音量の定義: `cmd/dinosaur-game/sound.go` の `effects` と `masterVolume`
- 再生タイミング: `game` パッケージが `Sounds()` でそのフレームに発生した音をビット集合で返すだけ（`game/sound.go`）

`game` 側が音を鳴らさないのは、フロントエンドによって鳴らせるかどうかが違うからです。

| ビルド | 効果音 |
| --- | --- |
| デスクトップ / Web (WASM) | サイン波を合成した PCM |
| ファームウェア | 鳴らない（#23） |

ジャンプ音だけは「地面を離れたフレーム」でのみ鳴ります。空中での押下やタイトル・ゲームオーバー画面の押下で鳴ると、入力を受け付けたように聞こえてしまうためです。
